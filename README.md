# QuantumTask

**QuantumTask** is an AI-powered productivity tool designed to minimize user friction (Smart Capture) and optimize workflow (Quantum Sorting).

## Architecture

- **Frontend**: Next.js (TypeScript)
- **Backend**: FastAPI (Python)
- **Database**: PostgreSQL
- **AI**: SpaCy / Scikit-learn (local NLP)
